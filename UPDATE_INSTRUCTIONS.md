# Инструкция по обновлению конфигурационных файлов / Configuration Setup Guide

Этот проект разработан с архитектурой полного разделения данных и интерфейса. Весь текст, ссылки на изображения, список проектов, стек технологий и контактная информация хранятся в двух файлах формата JSON в папке `/src/data/`. Это позволяет легко обновлять сайт без изменения самого программного кода.

---

## 1. Файлы конфигурации

### 📁 Файл `/src/data/content.json` (Общие тексты и ссылки)
Управляет текстовым наполнением разделов сайта, меню навигации, заголовками и ссылками на социальные сети.

**Основные разделы структуры:**
*   `siteName`: Название сайта/проекта (отображается в шапке и подвале).
*   `navigation`: Список ссылок меню в верху и внизу сайта.
*   `hero`: Информация на первом экране (статус доступности, заголовки, описание, кнопки и фотографии).
    *   `avatarUrl` и `altAvatarUrl` определяют ссылки на портретные фото.
*   `sections`: Тексты для разделов:
    *   `stack`: Стек технологий.
    *   `services`: Услуг и экспертизы.
    *   `portfolio`: Избранных проектов.
    *   `about`: Раздел "Обо мне" (абзацы текста и цифровые показатели - `stats`).
    *   `contact`: Заголовок, описание, email, telegram для формы обратной связи.
*   `footer`: Слоган и ссылки в подвале.

**Пример редактирования блока подвала:**
```json
"footer": {
  "tagline": "Разработка с точностью до пикселя.",
  "links": [
    { "label": "GitHub", "url": "https://github.com/my-nickname" },
    { "label": "Telegram", "url": "https://t.me/my-telegram" }
  ]
}
```

### 📁 Файл `/src/data/portfolio.json` (Портфолио, стек и услуги)
Управляет списком ваших проектов, используемыми технологиями и подробным описанием оказываемых услуг.

#### 🛠️ Секция `projects` (Проекты)
Массив объектов. Каждый проект содержит следующие поля:
*   `id`: Уникальный идентификатор (например, `"project-1"`).
*   `title`: Название проекта.
*   `description`: Краткое описание реализованного функционала.
*   `tags`: Массив используемых технологий (отображаются в виде тегов).
*   `imageUrl`: Ссылка на обложку проекта (можно использовать хотлинк на картинку).
*   `projectUrl`: Ссылка на живую версию проекта или GitHub-репозиторий.

#### ⚙️ Секция `techStack` (Стек технологий)
Массив технологий, отображаемый на главном экране. Поля:
*   `id`: Уникальный ID.
*   `name`: Название технологии (например, `"React"`).
*   `imageUrl`: Ссылка на официальную иконку технологии в высоком разрешении.
*   `letter`: (Необязательно) Буква для отображения текстовой заглушки, если картинка не указана (например, для Tilda).

#### 💼 Секция `services` (Услуги & Экспертиза)
Элементы сетки услуг. Поля:
*   `id`: Уникальный ID.
*   `title`: Название услуги.
*   `description`: Описание экспертизы.
*   `tags`: Ключевые слова / технологии для метки услуги.
*   `icon`: Имя иконки из библиотеки `lucide-react` (например: `"rocket"`, `"brain"`, `"palette"`, `"bolt"`, `"support"`).
*   `featured`: Если `true`, элемент растягивается в сетке и получает дополнительную подсветку.

## 2. Пошаговые действия для внесения изменений

1. Откройте нужный файл конфигурации (`/src/data/content.json` или `/src/data/portfolio.json`).
2. Внесите изменения (например, замените адрес электронной почты, добавьте новый тег проекта или ссылку на новую фотографию).
3. **Важно:** Следите за правильным синтаксисом JSON:
    *   Все строки и названия свойств должны быть закованы в двойные кавычки (`"property": "value"`).
    *   Элементы списков разделяются запятыми. В конце последнего элемента запятая **НЕ** ставится.
4. После сохранения файла изменения отобразятся на сайте автоматически без перезагрузки сервера в режиме разработки, либо вступят в силу при сборке.

## 🚀 Бонус: Интерактивный "DevMode" Режим на Сайте
Справа в верхнем углу сайта всегда присутствует кнопка **⚙️ DevMode / Editor**. Нажав на неё, вы откроете интерактивную панель управления прямо в браузере!
Это позволит вам:
- Редактировать любой текст и параметры портфолио в режиме реального времени.
- Видеть все изменения мгновенно прямо на странице.
- Скопировать готовый сгенерированный JSON-код одним кликом и вставить его обратно в файлы конфигурации.
